# Assistance Caddie

Pour obtenir de l’aide, signaler un problème ou proposer une amélioration, ouvrez une demande sur la [page Issues du projet Caddie](https://github.com/valentinprs/caddie/issues).

Avant de signaler un problème, indiquez si possible :

- le modèle de votre iPhone et la version d’iOS ;
- la version de Caddie ;
- les étapes permettant de reproduire le comportement observé.

N’incluez pas de données personnelles ou de contenu privé provenant de vos listes.
